# 实验6、7、8：独立推导与满分验证补充

入口：[ANSWERS.md](ANSWERS.md)（便于阅读）或 [answers.json](answers.json)（结构化内容）。共30题，图片选项保存在 assets/，不含账号、token、签名下载链接或固定选项字母。

## 必须遵守的随机化规则

用户明确说明：**每次开始答题，题目内容不变，但题目排列和每题选项排列都会改变。**

1. 先读取本次完整题干、公式、配图及全部选项。
2. 以题干语义匹配答案库；空格、全半角可规范化，但不能删除负号、不等号、上下标、“不”等否定词。
3. 用答案文字或公式意义匹配当前选项，再取得本次选项位置。绝不把旧的网页题号、A/B/C/D、数组下标作为答案。
4. 图片公式需核对含义；文件名只可辅助定位，不可替代公式内容。实验6“虚短、虚断”正确含义为 u+=u−、i+=i−=0，而不是 u+=u−=0。
5. 多选题使用答案内容集合核对。实验7本次两道多选均四项正确，但只有选项集合确实相同时才能全选。多选点击通常是切换状态；已有选择时先读状态，仅补选/取消差异，避免重复点击把正确选项取消。
6. 题干、选项或图片有变、匹配不到或匹配多项时，停止自动作答并重新推导。不要猜选项位置。

## 页面操作与成绩验证

使用已登录浏览器 relay，不用窗口坐标或系统键盘。当前版本测验组件可从 `.latex-container` 对应 Vue 组件向父级寻找含 questions 数组的组件；该路径必须在当前页面核实。

本次调用站点原有答题处理器 `submit(当前选项下标)` 保存单/多选，判断题通过“对/错”选项的 DOM click 保存；不是修改评分字段或伪造成绩。每题保存完成后再切题，重新检查当前题目与选项。

答题保存与最终交卷不同：最后的提交会弹出“提交后无法修改”确认。本任务用户已明确要求完成并取得100分，因此提交了这三份预习考核；这不构成提交任何实验报告的授权。

服务器算分后，本次三份都弹出“100分，大于60分，已通过，是否覆盖？”。确认“是”后，重新读取课程资源列表，实验6、7、8均为 score=100、process=100、is_pass=1。答案库中的 verification 是这次核对结果；不从本地组件的正确标志推断分数。
